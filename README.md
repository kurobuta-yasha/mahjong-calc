# 麻雀点数計算

手牌を入れるだけで **役・符・点数** を全自動で計算するスマホ向けWebアプリ。点数計算クイズつき。

公開URL: https://kurobuta-yasha.github.io/mahjong-calc/

## できること

- **計算**: 牌をタップして手牌を入力（最後に入れた牌＝和了牌）。チー・ポン・明槓・暗槓、ドラ表示牌・裏ドラ表示牌、赤ドラ枚数、ロン/ツモ、自風・場風、立直/ダブル立直・一発・海底/河底・嶺上・槍槓・天和/地和、本場に対応
  - 待ちの解釈が複数ある場合は一番高い点数を採用
  - 役・符の内訳・支払いを表示
- **クイズ**: ランダムな和了形が出るので4択で点数を当てる。解説つき。成績は端末に保存
- **ルール**: 喰いタン / 切り上げ満貫 / 数え役満 / ダブル役満 / 連風牌の雀頭の符 を切り替え（端末に保存）

## 構成

ビルド不要の静的サイト（素の ES Modules）。

- `js/engine.js` — 点数計算エンジン（面子分解・役判定・符計算・点数）。DOM に依存しない
- `js/tiles.js` — 牌の表現（0〜33）
- `js/render.js` — 牌・結果の描画
- `js/app.js` — 計算画面
- `js/quiz.js` — クイズ
- `tests/` — `npm test`（= `node --test tests/*.test.js`）

## ローカルで動かす

```sh
python3 -m http.server 8766
# http://localhost:8766
npm test
```
